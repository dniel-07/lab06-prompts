# Tarea: Mi prompt profesional

## Funcionalidad elegida

CRUD de productos. La aplicación permitirá registrar, consultar, actualizar y eliminar productos con datos como nombre, precio y stock.

## Version 1: prompt basico

```text
Crea un CRUD de productos.
```

## Version 2

Crea un CRUD de productos para una aplicación web. Cada producto debe tener nombre, precio y stock. Incluye las operaciones para crear, listar, actualizar y eliminar productos.

 
## Version 3: prompt final
 
ROL:
Actúa como un desarrollador web con experiencia en aplicaciones CRUD.

INSTRUCCIÓN:
Crea la estructura y el código necesario para un CRUD básico de productos que permita crear, listar, actualizar y eliminar productos.

CONTEXTO:
La aplicación será una aplicación web sencilla para gestionar productos. Cada producto tendrá los campos: nombre, precio y stock. La solución está dirigida a una persona que está aprendiendo desarrollo web.

EJEMPLO:
Un producto podría ser:
- Nombre: Teclado
- Precio: 25.90
- Stock: 10

FORMATO:
Entrega la respuesta organizada en:
1. Estructura de archivos.
2. Código de cada archivo.
3. Explicación breve de cómo funciona.
4. Pasos para ejecutar el proyecto.

RESTRICCIÓN:
No uses librerías externas innecesarias y mantén la solución simple y fácil de entender.

## Componentes del prompt final

|Componente | Dónde aparece |
|----------|-----------------------|
| Rol	| “Actúa como un desarrollador web...” |
| Instrucción	| “Crea la estructura y el código...” |
| Contexto	| Descripción de la aplicación y sus campos |
| Ejemplos |	Ejemplo del producto “Teclado” |
|Formato	| Estructura de archivos, código, explicación y ejecución|
 
## Evaluacion del resultado

|Criterio	|Resultado|
|-----|-------|
|Define claramente la funcionalidad	|Sí|
|Incluye contexto suficiente|	Sí|
|Indica el formato de respuesta|	Sí|
|Incluye un ejemplo	|Sí|
|Incluye una restricción|	Sí|
|Define un rol para la IA|	Sí|
 
## Errores que evite

Ser demasiado general
En la versión 1 solo se indicaba “Crea un CRUD de productos”. En las siguientes versiones añadí los campos, operaciones y contexto de la aplicación para reducir las interpretaciones posibles.

No indicar el formato
En la versión 3 especifico exactamente cómo debe organizarse la respuesta: estructura de archivos, código, explicación y pasos de ejecución. Esto permite obtener una respuesta más ordenada y fácil de utilizar.
